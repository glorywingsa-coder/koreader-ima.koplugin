IMA 知识库 · v0.6.34

通过腾讯 ima 官方开放平台接口，浏览与检索个人知识库。

本版已实现：
· 未配置凭证时点插件默认走扫码登录，扫完直接进列表
· 扫码登录：手机微信扫一下设备上的二维码即可获取凭证
· 浏览知识库列表与目录
· 按名称搜索知识库
· 在知识库内检索内容
· 点条目在线阅读（PDF / Word / 图片等 KOReader 支持的格式）
· 笔记正文读取
· 阅读器用 KOReader 原生界面：物理翻页键、点按翻页、字体排版、阅读器菜单全部可用；退出即回到知识库列表
· 翻页不切断文字：按文档真实行位置对齐，屏幕底部总收在整行上
· 阅读界面顶部下滑返回知识库列表（与列表里的下滑手势一致；顶部点按仍可打开阅读器菜单）
· 退出阅读器只关阅读器，不会闪出 KOReader 的文件列表
· 不替用户改版面、也不改阅读姿态：文档按 KOReader 自己的默认（竖屏）打开，字号 / 行距在阅读器「排版」面板里自己调
· Word（.docx）直接打开：KOReader 把它交给 crengine —— 与 EPUB 同一个排版引擎，所以字号、行距、边距本来就能调，表格与插图也都保留
· PDF 自动重排为可调字号：打开 PDF 时用 MuPDF 取出版面上的文字、重新拼段落后落成 HTML，由 crengine 渲染（与 EPUB 同一个排版引擎）—— 字号、行距、边距都能在阅读器「排版」面板里调；标题与正文同字号、只保留加粗；矢量图表不保留，可在设置里关掉这一项

凭证获取：https://ima.qq.com/agent-interface
